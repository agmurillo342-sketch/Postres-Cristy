# Postres Cristy

Sitio web estático de una sola página para mostrar postres y recibir pedidos por WhatsApp.

## Archivos

- `index.html`: estructura y contenido de la página.
- `styles.css`: estilos responsive y paleta pastel.
- `script.js`: validación de pedidos y enlaces a WhatsApp.

## Personalizar

En `index.html` puedes duplicar cualquier bloque `.dessert-card` para agregar más productos. Cambia el nombre, precio y el contenido visual de la tarjeta.

El número de WhatsApp está en la constante `WHATSAPP_NUMBER` dentro de `script.js`.
